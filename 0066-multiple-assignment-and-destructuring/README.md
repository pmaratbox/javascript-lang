# 0066 — Multiple Assignment & Destructuring

Swap two variables (`a = 1`, `b = 2`) with a single multiple-assignment, then unpack the pair `(3, 4)` into two variables — printing `2 1` then `3 4`. Array destructuring `[a, b] = [b, a]` swaps in one statement, and `const [x, y] = [3, 4]` unpacks an array into two bindings.

## Run

    node main.js
