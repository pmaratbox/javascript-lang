# 0009 — Maps

Build a map `{"one": 1, "two": 2, "three": 3}`, look up `"two"`, and print its
value and the map's size. `Map` is the dedicated key-value type: `.get(key)`
reads a value and `.size` counts entries. A plain object `{}` also works as a
string-keyed dictionary, but `Map` keeps insertion order, allows any key type,
and exposes `.size` directly.

## Run

    node main.js
