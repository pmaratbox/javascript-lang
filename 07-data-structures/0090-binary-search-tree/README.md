# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. `insert` places smaller values left and the rest right; in-order traversal (left, node, right) emits a BST in sorted order.

## Run

    node main.js
