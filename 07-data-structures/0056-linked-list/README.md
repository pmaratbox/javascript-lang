# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. A `Node` class stores `value` and `next` (defaulting to `null` at the tail); walking `node = node.next` until `null` traverses the list, since objects are references.

## Run

    node main.js
