# 0060 — Priority Queue

Push `3`, `1`, and `2` into a min-priority-queue, then pop them all and print them in priority (ascending) order: `1 2 3`. JavaScript has no priority queue; this is an array-backed one — `push` inserts in sorted position so the front is always the minimum. A binary heap is the O(log n) alternative.

## Run

    node main.js
