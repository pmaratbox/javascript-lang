# 0007 — Collections

Build an array of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. Arrays are dynamic and `.length` is a property. The
`[]` operator does not accept negative indices — compute `length - 1`, or use
the modern `nums.at(-1)` (ES2022).

## Run

    node main.js
