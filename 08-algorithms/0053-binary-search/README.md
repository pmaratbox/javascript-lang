# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. `Math.floor((lo + hi) / 2)` computes the midpoint because `/` is floating-point division. JavaScript has no built-in binary search, so the loop is written by hand.

## Run

    node main.js
