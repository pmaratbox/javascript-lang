# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `Number.prototype.toString(radix)` renders the number in any base from 2 to 36, so `toString(16)`, `(8)`, and `(2)` give hex, octal, and binary without a prefix.

## Run

    node main.js
