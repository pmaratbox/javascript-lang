# 0089 — Quicksort

Sort the list `3, 1, 4, 1, 5, 2` using quicksort (partition around a pivot, then recurse on each side) and print the result: `1 1 2 3 4 5`. `filter` partitions the rest around the pivot; spreading the two recursively sorted halves around the pivot rebuilds the sorted array.

## Run

    node main.js
