# 0674 — Node degree

Using the **graphlib** library, build the fixed weighted undirected graph G and report a node's *degree* — the count of edges incident to it. In an undirected graph the degree equals the number of neighbors, so `g.neighbors("b").length` returns the degree of node `b` (which connects to `a`, `c`, and `d`).

## Run

    node main.js
