# 0673 — Build a graph

This lesson uses the `graphlib` library to construct the fixed weighted undirected graph G (nodes a–e, edges a-b, a-c, b-c, b-d, c-d, d-e). Each edge is added with `setEdge`, and the library's `nodeCount()` and `edgeCount()` accessors report the totals, printed space-joined.

## Run

    node main.js
