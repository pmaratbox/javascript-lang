# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. An object's values come from `Object.values`, which `reduce` then folds into a total. `Object.keys` and `Object.entries` give the keys and key/value pairs.

## Run

    node main.js
