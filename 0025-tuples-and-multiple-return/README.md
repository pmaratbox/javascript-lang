# 0025 — Tuples & Multiple Return

Return both the smaller and larger of `3` and `7` from one function, unpacking the pair to print `min: 3` and `max: 7`. JavaScript has no tuple type, so the two values are returned as an array `[lo, hi]` and pulled out with array destructuring `const [lo, hi] = ...`. Position, not name, determines each binding.

## Run

    node main.js
