# 0037 — Operator Overloading

Define how `+` (or an `add` method) combines two points, then add `(1, 2)` and `(3, 4)` and print `(4, 6)`. JavaScript has no operator overloading, so a named `add` method does the combining; `+` only works on numbers and strings. `toString` customizes string coercion.

## Run

    node main.js
