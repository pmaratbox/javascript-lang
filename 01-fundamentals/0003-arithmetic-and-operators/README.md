# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). JavaScript has only a single `number` type
(double-precision float), so `17 / 5 → 3.4` — there is no integer
truncation. Use `Math.trunc(a / b)` for truncated integer quotient.

## Run

    node main.js
