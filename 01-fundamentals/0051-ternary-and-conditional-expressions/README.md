# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. The C-style ternary `cond ? a : b` selects between two values inline. It is the only conditional *expression* in JavaScript (the `if` statement does not produce a value).

## Run

    node main.js
