# 0034 — Default & Named Arguments

Give a `greet` function a default greeting, then call it once without the greeting and once overriding it, printing `Hello, Ada` and `Hi, Ada`. A default parameter (`greeting = "Hello"`) fills in when the argument is missing or `undefined`. JavaScript has no named arguments — callers pass positionally, or destructure an options object `{ greeting }` to fake them.

## Run

    node main.js
