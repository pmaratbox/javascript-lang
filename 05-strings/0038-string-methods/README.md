# 0038 — String Methods

Split `"a,b,c"` on commas, upper-case each part, and join them with `-`, printing `A-B-C`. `split(",")` yields an array, `map` with `toUpperCase()` transforms each element, and `join("-")` recombines them. All string methods return new strings since strings are immutable primitives.

## Run

    node main.js
