# 0004 — Conditionals

Compare `n` against 10 and print whether it's less, equal, or greater.
JavaScript wraps the condition in parentheses and the body in braces.
Use `===` (strict equality) — `==` coerces types and is a footgun. Edit
`n` to `10` or `15` to exercise the other branches.

## Run

    node main.js
