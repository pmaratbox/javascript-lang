# 0032 — Math Functions

Take the square root of `16`, raise `2` to the 10th power, the absolute value of `-5`, and the larger of `3` and `9`, printing `sqrt: 4`, `pow: 1024`, `abs: 5`, and `max: 9`. Numeric helpers are static methods on the `Math` object: `Math.sqrt`, `Math.pow` (or the `**` operator), `Math.abs`, and `Math.max`. Since every JavaScript number is a float, `Math.sqrt(16)` already prints as `4` with no cast.

## Run

    node main.js
